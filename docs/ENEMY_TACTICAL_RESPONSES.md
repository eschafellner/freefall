# Taktische Operatorhaltungen · 7.4C

| Haltung | Wirkung auf den Angriff |
| --- | --- |
| STANDING | Gewohnte Reichweite zur Mitte. Die Trefferprüfung nutzt die tatsächliche aufrechte Box. |
| CROUCHING | Ziel bleibt gültig. Kontakt braucht Überlappung mit der niedrigen Box. |
| SLIDING | Die verlängerte, gedrehte Box und die bereits ausgeführte Bewegung bestimmen die Erreichbarkeit. |
| DIVING | Aktueller Weg, Ausrichtung und Höhe kommen aus dem regulären Server-Dive. In der Absprungvorbereitung gilt die Ausgangsform, danach das Flugvolumen. Seitlicher oder vertikaler Abstand kann einen Treffer verhindern. Bei Kontakt gelten die regulären Schadenswerte. |
| PRONE / SUPINE | Anmarschpunkte um den Operator bleiben verfügbar. Die Orientierung des Körpers richtet Kopf-, Torso- und Beinzonen aus. Bei einem senkrechten Mismatch zählt die Zone als unerreichbar. |
| GETTING_UP | Die Box wächst mit der validierten Aufstehtransition. Der Operator kann in jeder Phase getroffen werden, wenn das aktuelle Volumen erreicht wird. |

Das auf dem Server ausgeführte Movement liegt vor der Trefferprüfung. Der Windup bindet die Schlagrichtung. Die KI reagiert beim nächsten Anmarsch auf die tatsächlich erreichte Spielerposition. Ein Dive benötigt Platz zum Ausweichen und gewährt keine zusätzlichen Schutz-Ticks. Die Tests prüfen links- und rechtsseitiges Ausweichen sowie einen bestätigten Treffer bei einem späten Dive in der Luft. [Verifikation](ENEMY_AI_PLAYTEST.md)
