# Planetare Einschläge

| Welt | Darstellung im Spiel |
| --- | --- |
| Eis | Heller, kompakter Schneeaufwurf. Kleine, kühle Splitter auf Eis. Gefrorener Fels erhält dunklere, körnige Splitter. |
| Wüste | Kurzer sandfarbener Staub mit grobem Korn. Verdichteter Boden wirft kleinere, schwerere Partikel auf. Felsen erzeugen kurze Splitter. |
| Grüne Ebene | Olivfarbene Bodenpartikel auf Gras, Erdkorn auf offenen Stellen und helle Splitter auf Fels. |
| Wald | Dunkler, niedriger Aufwurf mit Blattstreutönen. Vorhandene Stamm-Collider werfen helle Holzsplitter aus. Felsen behalten ihren Steinimpuls. |
| Technische Flächen | Enger, kurzer Funkenimpuls für Metall. Die Betonflächen nutzen einen matten Splitter- und Staubimpuls. |

Korn und Staub starten am Weltkontakt. Der erste Impuls nutzt die Normale und die tangentiale Komponente der Schussrichtung. Leichter Staub übernimmt mit zunehmendem Alter einen Anteil des vorhandenen visuellen Wetterwinds. Die Partikel respektieren das Szenenfog. Im Kameranahbereich unter 42 cm entfällt die Partikelgruppe. Staub beginnt jenseits von 1,5 m.
