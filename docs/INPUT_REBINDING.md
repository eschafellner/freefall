# Tastenbelegung und Kamera

Die Einstellungen sind im Menü unter **Steuerung und Kamera** verfügbar. Eine Aktion auswählen und die gewünschte physische Taste oder Maustaste drücken. Bereits verwendete Eingaben zeigen die betroffene Aktion an. Esc bricht den Erfassungsmodus ab. **Standardbelegung wiederherstellen** setzt die Aktionen zurück. Der Browser speichert die Belegung lokal pro Origin.

| Aktion | Standard |
| --- | --- |
| Bewegen | W, A, S, D |
| Sprinten | Shift |
| Ducken | C |
| Hechtsprung | X |
| Aufstehen | Leertaste |
| Zielen / Feuern | Rechte / linke Maustaste |
| Nachladen / Nahkampf | R / V |
| Granate / Heilstim | G / H |
| Primär- / Sekundärwaffe | 1 / 2 |
| Interagieren / Rettungsballon | E / B |

Bezeichnungen im Einsatz-HUD folgen der aktiven Belegung. Shift links und rechts sind gleichwertig. Die Menü- und Telemetrietasten bleiben reserviert. Unter derselben Einstellung lassen sich Kamerawackeln, Glättung und reduzierte Bewegung einstellen. Ein gesetzter Systemwunsch nach reduzierter Bewegung dient als Voreinstellung.

Die Eingabeschicht trennt physische Codes, Aktionen und ihre Netzwerkwerte. Der Netzwerkvertrag akzeptiert analoge Bewegungsachsen. Die Desktop-Oberfläche belegt Tastatur und Maustasten. Anschlüsse für Gamepad und Touch können denselben Vertrag verwenden.
